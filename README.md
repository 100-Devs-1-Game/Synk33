SYNK:33 is a high-energy, narrative-driven rhythm game set in a world bathed in synthetic light in the city of Beatopia. The game centers on the concept of "Synking", a futuristic way to experience music through advanced haptic feedback and VR technology using the SYNK:33 headset.

SYNK:33 is part of the 33 games made in 100 days gamejam game hosted by CGGJ (Collaborative Godot Game Jam)
